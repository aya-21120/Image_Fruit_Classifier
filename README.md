# Image_Fruit_Classifier

## Description

This project focuses on building an image classification model to identify seven different types of fruits using deep learning techniques. The model was trained and tested on a labeled dataset of fruit images.

##  Model & Tools

* PyTorch
* Google Colab
* CNN / ResNet

## Results

Accuracy: **72%**
